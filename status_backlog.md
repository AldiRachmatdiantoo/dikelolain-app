## Posisi kerja terakhir

> Dibaca pertama kali saat melanjutkan pekerjaan (misalnya setelah konteks percakapan diringkas). Diperbarui setiap PBI selesai.

**Mode:** eksekusi otomatis atas instruksi pemilik (3 Nov 2026): kerjakan PBI berurutan tanpa bertanya, uji setiap PBI (`php artisan test` + cek browser bila terlihat), commit + push per PBI, kendala dicatat di [kendala_backlog.md](kendala_backlog.md).

**Rilis:** sejak 9 Nov 2026 **dikelolain.com menjalankan versi ini** (PBI-504 selesai), dengan isi asli web lama yang dipindahkan lewat PBI-520. Susunan di Hostinger (Single Web Hosting, tanpa SSH, [DEPLOY.md](DEPLOY.md#hostinger-single-web-hosting-tanpa-ssh)):

- Kode di `~/dikelolain-v2`, database `u592845481_dikelolainv2` (MariaDB 11.8).
- `public_html` berisi salinan `public/` dengan tiga path `index.php` mengarah ke `../dikelolain-v2/`, plus symlink `public_html/storage`.
- Jalan kembali: `public_html_lama`, folder `dikelolain-app`, dan database lama dibiarkan beberapa minggu. Untuk kembali, tukar lagi isi `public_html` dengan `public_html_lama`.
- File CSS bundle dan font ikon di server masih build sebelum banner Portfolio dihapus (lebih lengkap, tidak merusak tampilan); ikut diperbarui saat kode diunggah lagi.

**Belum dikerjakan:** tugas pemilik setelah rilis di KD-7 (coba mode edit, ganti password admin, hapus folder `public_html_baru` yang sudah kosong), konten di KD-5, dan PBI-507 (PHP 8.3 + OPcache di hPanel). 502 menunggu konten asli (KD-2). PBI-508 (cache) diukur dan dinilai tidak perlu, 505 belum diisi.

Data asli lokal (tidak masuk git): `storage/app/private/live/` (dump SQL 9 Nov 2026 dan `media.zip`), paket deploy di `storage/app/private/deploy/`, MySQL Laragon `live_old` (dump mentah) dan `live_new` (hasil ubahan).

**Contoh pola entitas = Testimonial** (memakai kerangka daftar bersama, [ARCHITECTURE §7.1](ARCHITECTURE.md#71-kerangka-bersama-untuk-daftar-terurut)). Entitas berikutnya meniru file-file ini:
- `database/migrations/2026_11_03_000003_create_testimonials_table.php`, `app/Models/Testimonial.php` (scope + accessor `logo_url`/`photo_url`)
- `app/Repositories/{Contracts/TestimonialRepositoryInterface,Eloquent/EloquentTestimonialRepository}.php` + binding di `RepositoryServiceProvider`
- `app/Services/TestimonialService.php` (`$images`), `app/Services/Pages/TestimonialPageService.php`
- `app/Http/Requests/Admin/TestimonialRequest.php`, `app/Http/Resources/TestimonialResource.php`, `app/Http/Controllers/Admin/Api/TestimonialController.php` + satu baris di `$lists` (`routes/web.php`)
- `app/Http/Controllers/Pages/TestimonialPageController.php`, `app/Vcms/Fields/TestimonialFields.php`, `database/seeders/TestimonialSeeder.php` (+ `DatabaseSeeder`)
- Test: `tests/Feature/TestimonialApiTest.php` (pakai `ListApiContract`), `TestimonialPageTest.php`
- Data untuk partial yang tampil di semua halaman (footer) diberikan lewat view composer (`app/View/Composers/FooterComposer.php`, didaftarkan di `AppServiceProvider`), jadi halaman 404 pun punya datanya.
- Section yang muncul di beberapa halaman: satu partial di `resources/views/partials/` + satu method di `app/Services/Pages/SectionData.php` (contoh: `tools()` + `partials/creative-tools.blade.php`); page service cukup menggabungkan `...$this->sections->tools($editing)`.
- Kode lama dipotong dengan skrip penanda (scratchpad `cut.php`/`swap.php`: hapus teks di antara dua penanda yang masing-masing harus unik), lalu `php -l` (dan `node --check` untuk file JS).

**Catatan cek browser:** panel browser yang tersembunyi tidak menjalankan animasi/transisi. Modal Alpine (`x-transition`) dan elemen dengan `transition` dari template terlihat "macet" sampai panel dirender (misalnya diambil screenshot). Ini bukan bug. Screenshot panel kadang terpotong; untuk alur editor lebih andal cek lewat DOM/`fetch`.
